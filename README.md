리스트 자료구조: 리스트 자료구조는 데이터를 나란히 저장한다. 중복을 막지 않는다.
* 1. 배열 기반 리스트 : 배열 기반이라 참조가 빠르지만, 삽입 삭제할 때 대규모 이동이 필요하다는 단점이 있다. 또한 처음에 메모리가 정해진다.
  2. 연결 리스트  : 삽입 삭제가 쉽고, 메모리를 계속해서 늘릴 수 있다.

연결 리스트 종류: 단순 연결 리스트, 원형 연결 리스트, 이중 연결 리스트

단순 연결 리스트라 함은 단순히 리스트에다가 요소들을 추가하는 리스트이다. 방향도 헤더에서 끝으로 밖에 못간다. 다만 SetSortRule로 정렬의 기준을 정해 삽입을 정렬로 할 수 있다는 것도 배웠다.
원형 연결 리스트는 끝에서 다시 처음으로 돌아갈 수 있는 구조이다.
이중 연결 리스트는 prev가 필요 없는 구조로 노드의 이전으로 갈 수 있는 구조이다.

스택 자료구조: 배열 기반 스택, 연결 리스트 기반 스택
둘 다 push, pop의 시간 복잡도가 O(1)이지만 사실 동적할당과 캐시 미스 때문에 배열 기반 스택이 더 유리하다. 스택은 LIFO구조를 가졌다.

스택 기반 활용: 계산기 프로그램 -> 1. 중위표기법을 후위표기법으로 바꾸기 2. 후위표기법을 계산하는 프로그램 만들기.
1, 2 둘 다 stack 필요함. 

큐 자료구조: 배열 기반 큐, 연결 리스트 기반 큐
스택의 push, pop이 enqueue, dequeue로 불리며, 맨 첫 번재에 들어온 것이 맨 첫 번째로 나간다. FIFO구조라 한다.
배열 기반 큐 같은 경우, front, rear를 두는데 front를 움직이면 전체 메모리를 사용하기 위해 원형 구조로 만들어야 한다. 배열의 끝에 다다르면 0으로 이동하는 방식말이다.
하지만 그러면 텅빈 경우와, 다 찬 경우의 front rear 상대 위치가 같아 구분을 하지 못한다. 따라서 공간 하나를 빈 원형 큐를 많이 사용한다.
연결리스트 기반 큐는 front와 rear를 두면 되는데, 메모리 자체를 계속 동적할당하니 memory가 줄어들지 않아 굳이 circular 안해도 되서 구현 자체는 쉽다.

큐 예시: 큐잉 이론 시뮬레이션-> 햄버거 가게에서 주문시 얼마나 대기실 수용량을 만들어야 하는가 등 보기

덱 자료구조: 덱은 deque로 double-ended-queue의 줄임말이다. 스택이 뒤로넣고 뒤로뺄수만 있고, 큐가 앞으로 넣고 뒤로 뺄 수 있다면, 덱은 앞으로 넣고, 뒤로 넣고, 앞으로 빼고, 뒤로 뺄 수 있는 자료구조이다.

덱은 배열로도 만들 수 있고 연결리스트 기반도 가능하다. 연결리스트 기반으로 할거면 이중 연결 리스트를 사용해야한다. 뒤로 빼기 때문에 prev로 갈 수 없다면 힘들기 때문이다.

트리: 비선형 구조, 연결리스트와 배열 기반 모두 가능하지만, 공간만 괜찮다면 배열기반이 훨씬 빠름.
따라서 완전 이진트리라면 배열기반으로 구성하는게 무조건 좋다. 공간을 다 쓸 수 있으니까..

이진 트리: 노드 기반으로 이루어져 있는데, 재귀적으로 이루어진게 특징이다. 
1. 공집합 노드, 즉 아무 노드가 없는 것도 이진트리이다.
2. 루트 노드 및 왼쪽, 오른쪽에 이진트리도 이진트리이다.
이러한 구성 때문에 이진트리는 재귀적인 성질을 갖는다.

그래서 이진트리의 순회 또한 재귀적인 특징을 갖는다.

전위순회(preorederTraverse), 중위순회(inorderTraverse), 후위순회(PostOrderTraverse)

이진트리의 중위순회를 예를 들겠다.
1. 왼쪽 서브트리를 탐색한다.
2. 루트 노트를 탐색한다.
3. 오른쪽 서브트리를 탐색한다.

왼쪽 서브 트리, 오른쪽 서브 트리 모두 이진트리이다. 따라서 재귀적으로 할 수 있다. 재귀적으로 하다가 종료 시점만 잘 정해주면 된다.
나머지 전위, 후위는 1, 2, 3의 순서만 달라질 뿐이다.

전위순회
1. 루트 노트를 탐색한다.
2. 왼쪽 서브트리를 탐색한다.
3. 오른쪽 서브트리를 탐색한다.

후위순회
1. 왼쪽 서브트리를 탐색한다.
2. 오른쪽 서브트리를 탐색한다.
3. 루트 노트를 탐색한다.

이진 트리의 예: 수식트리 (수식 트리는 이진 트리인데, 만들기 위해서 스택도 필요함. LIFO구조)
전위순회를 하면 전위표기법이, 후위순회를 하면 후위표기법이, 중위 순회를 하면 중위표기법이 나타난다. (이진트리의 신기함)
중위표기법은 다만 괄호가 필요하기에 괄호를 설정해줘야 한다.
수식트리의 값을 계산하는 것도 이진트리가 재귀적 구조를 갖기 때문에 재귀함수로 구현할 수 있다.

우선순위 큐: 큐와 비슷하게 enqueue dequeue를 하지만, 우선순위가 높은 걸 먼저 뺀다. 먼저 입력한 걸 먼저 빼는 구조하고는 다르다.
우선순위 큐는 배열, 연결리스트, 힙 중 하나로 만들 수 있는데 배열과 연결리스트는 삽입시 모든 요소의 우선순위를 다 봐야한다 따라서 시간복잡도 n으로 굉장히 힘들다.
연결리스트은 맨 앞에 우선순위가 높은 걸 둔다고 가정할시 삽입시 O(n), 삭제시 O(1).
배열 기반은 맨 앞에 우선순위가 높은 걸 두고 circular로 구현한다고 가정할시 삽입시 O(n), 삭제시 O(1).

따라서 우리는 우선순위 큐에 딱 적합한 힙 기반으로 만들어야 한다. 힙은 완전이진트리로 배열기반으로 만든다.
삽입시 O(lgn) 삭제시 O(lgn)이다. 따라서 우리는 우선순위큐를 힙으로 구현해야한다. 
삽입의 방법은 맨 마지막 요소로 추가한 후 부모 노드와 비교하며 올라오는 방식이다.
삭제의 방법은 맨 위의 요소를 뺀 후, 맨 마지막 요소를 맨 위로 움직인 후, 자식의 노드 중 좀 더 우선순위가 높은 노드와 비교를 한다.
